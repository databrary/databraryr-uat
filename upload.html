Create/Update/Delete

About

This documents the results of testing functions that involve session and folder creation, file uploads, record creation and deletion, and session, folder, and file deletions.

Important

To make use of them, the tester must have write privileges on a Databrary volume.

Warning

These tests presume that the tester is accessing the test environment using a regular, Authorized Investigator, account.
